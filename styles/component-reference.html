Design System

This is the OpenCollab design system. The same tokens.css + components.css render this page and drive index.html and app.html. A living catalogue — every component below is the real one, not a copy.

Edit one place, change it everywhere. Tokens are the single source of truth; primitives read from them; the live app inherits both. No component CSS is duplicated here — this catalogue links the production stylesheets directly.

styles/tokens.css
CSS custom properties — surfaces, borders, text, accent, semantic colors, radii, spacing, shadows, type & motion.
styles/components.css
Token-driven primitives — buttons, fields, badges, diffs, tags, avatars, tabs, toasts, dialogs, editor & test rows.
styles/app/base.css + app/*.css
Per-surface partials (auth, dashboard, sessions, problem, editor, notes) that compose the primitives into screens.
styles/reference/linear-interview-components.html
The visual north star — the Linear interview library this system is modelled on.

Feedback

Toasts & dialogs

Coding surface

Code editor

Monospaced, line-numbered, with an active-line marker and a blinking caret. File tabs, language selection, and run live in one compact bar. Syntax colors come from the .tk-* token classes.
